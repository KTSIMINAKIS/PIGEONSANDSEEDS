# Pigeons and Seeds Android Application

A business management application with two components:
- SEEDS: For businesses to manage offers and locations
- PIGEONS: For users to receive notifications about nearby offers

## Features
- Business profile management
- Offer creation and management
- Geofencing for location-based notifications
- Push notifications
- Firebase integration

## Setup Instructions
1. Install JDK 17 or later
2. Set JAVA_HOME environment variable
3. Clone this repository
4. Open project in Android Studio
5. Build and run the application

## Requirements
- Android Studio
- JDK 17+
- Firebase account
- Google Maps API key
